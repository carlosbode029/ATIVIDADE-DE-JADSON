# BK CRÉD

Landing page premium para transformar o limite do cartão de crédito em dinheiro via PIX, com simulador em tempo real e direcionamento para WhatsApp.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide Icons

## Rodando localmente

```bash
npm install
npm run dev
```

## Configuração

Atualize o número de WhatsApp em `src/lib/whatsapp.ts` (`WHATSAPP_NUMBER`) para o número real de atendimento antes de publicar.
